LvlUp Next.js prototype

This folder contains a minimal Next.js + TypeScript + Tailwind prototype scaffold for the LvlUp project. It is intentionally small: run `npm install` and `npm run dev -w frontend-next` after installing dependencies to try locally.

Included:
- pages for each module (skeleton)
- shared UI components (GlassCard, Button, Navbar)
- MainLayout with glassmorphism and animated background
- Tailwind and PostCSS config
- Framer Motion integrated

This is a starting skeleton only — expand components and wire functionality as needed.
